Graph traversal means visiting connected items.

Like walking through a map and checking places one by one.

A graph traversal starts from one vertex and follows edges to systematically discover reachable vertices.

Part 1

Breadth-First Search

Also called BFS.

BFS visits vertices by distance in edges from the start: the start first, then its neighbors, then the next layer.

06 BFS Analogy

Explore Nearby First

BFS is like asking:

  • Who is directly beside me?
  • After that, who is beside them?
  • Then who is beside the next level?

Finishing one level before moving deeper makes BFS suitable for shortest paths in unweighted graphs.

07 Important Tool

BFS Uses a Queue

Queue rule: First In, First Out.

The first vertex waiting in line is processed first.

front
A
B
C
back

The queue preserves discovery order, so the earliest discovered unprocessed vertex is explored first.

08 BFS Core Rule

The Simple Recipe

  1. Put the starting vertex into the queue.
  2. Mark it as visited.
  3. Remove one vertex from the front of the queue.
  4. Add its unvisited neighbors to the queue.
  5. Repeat until the queue is empty.

Mark a vertex when it enters the queue so the same vertex is not added repeatedly through another edge.

12 Pseudocode

BFS in Plain English

// Breadth-First Search
create a queue
create a visited set
add start to queue
mark start as visited

while queue is not empty:
  remove the front vertex
  print the vertex
  for each neighbor:
    if neighbor is not visited:
      mark it visited
      add it to queue

Remove one vertex from the front, process it, then offer each unvisited neighbor to the back.

15 Helper Method

Add One Connection

static void addEdge(HashMap<String, ArrayList<String>> graph,
        String from, String to) {
  graph.get(from).add(to);
  graph.get(to).add(from);
}

Because our graph is undirected, we add the connection both ways.

16 BFS Code

The BFS Method

static void bfs(HashMap<String, ArrayList<String>> graph, String start) {
  Queue<String> queue = new LinkedList<>();
  HashSet<String> visited = new HashSet<>();

  queue.offer(start);
  visited.add(start);

  while (!queue.isEmpty()) {
    String current = queue.poll();
    System.out.println(current);
  }
}
17 BFS Code

Add the Neighbors

for (String neighbor : graph.get(current)) {
  if (!visited.contains(neighbor)) {
    visited.add(neighbor);
    queue.offer(neighbor);
  }
}

This part prevents repeating the same vertex again and again.

Neighbor iteration order can affect the exact printed order, but BFS still processes vertices level by level.

18 Important

Why Do We Need visited?

Without visited

A may add B, then B may add A again. The program may keep repeating.

With visited

Each vertex is processed only once. The search finishes safely.

Graphs may contain cycles or multiple paths to one vertex; visited prevents repeated processing and endless loops.

Part 2

Depth-First Search

Also called DFS.

DFS follows one branch as far as possible before returning to try another branch.

20 DFS Analogy

Follow One Path First

DFS is like entering a hallway:

  • Keep moving forward if there is an unvisited path.
  • When there is nowhere else to go, go back.
  • Try the next unvisited path.

When a path ends or reaches an already visited vertex, DFS backtracks to the most recent unfinished choice.

21 DFS Tool

DFS Uses a Stack Idea

DFS can use an actual Stack, or it can use recursion.

For beginners, recursion means: a method calls itself to continue exploring.

Recursive DFS uses the call stack implicitly; iterative DFS can use an explicit Stack object.

22 DFS Recipe

Recursive DFS Steps

  1. Visit the current vertex.
  2. Mark it as visited.
  3. Look at each neighbor.
  4. If a neighbor is not visited, call DFS on that neighbor.
  5. When a path ends, Java returns to the previous call.

The method marks the current vertex, processes it, then recursively explores each unvisited neighbor.

24 Pseudocode

DFS in Plain English

// Depth-First Search
dfs(current):
  mark current as visited
  print current

  for each neighbor of current:
    if neighbor is not visited:
      dfs(neighbor)

Each recursive call pauses the current vertex while a deeper neighbor is explored.

25 DFS Code

The DFS Method

static void dfs(HashMap<String, ArrayList<String>> graph,
        String current, HashSet<String> visited) {
  visited.add(current);
  System.out.println(current);

  for (String neighbor : graph.get(current)) {
    if (!visited.contains(neighbor)) {
      dfs(graph, neighbor, visited);
    }
  }
}
26 Calling DFS

Start the Search

HashSet<String> visited = new HashSet<>();
dfs(graph, "A", visited);

We pass the same visited set so Java remembers which vertices were already explored.

27 Compare

BFS vs DFS

BFS

  • Uses queue
  • Explores level by level
  • Good for shortest path in unweighted graphs

DFS

  • Uses recursion or stack
  • Explores deep paths first
  • Good for checking connected areas

Both visit reachable vertices in linear graph time, but their frontier order and practical uses differ.

28 When to Use BFS

BFS is Useful When...

  • You need the shortest number of steps.
  • You want to explore nearby items first.
  • Example: shortest route with equal road costs.
  • Example: fewest friendship connections between people.

BFS is a natural choice for minimum-edge routes, level order, and nearest-match searches in unweighted graphs.

29 When to Use DFS

DFS is Useful When...

  • You need to explore all possible paths.
  • You want to check if something is reachable.
  • Example: maze exploration.
  • Example: checking connected components.

DFS is useful for path exploration, cycle-related tasks, connected components, and dependency-style searches.

Important Reminder

BFS and DFS may visit the same vertices...

but the order of visiting can be different.

36 Common Error

No visited Set

The program keeps repeating or does not finish.

Graphs can contain cycles. visited helps the program avoid walking in circles.

Without visited, an undirected edge can send the search back and forth forever between the same vertices.

37 Common Error

Mixing Queue Methods

For Queue

offer() adds
poll() removes

For Stack

push() adds
pop() removes

For BFS, add with offer and remove with poll so the collection follows first-in, first-out order.
