03 Connection

A Stack Is Not New Magic

A stack is a way of organizing data where we only work with the item on top.

Linked List

Nodes connected by arrows

Stack

Items placed on top of each other

A stack is an access rule for a collection: additions and removals happen only at one end called the top.

Real-Life Analogy

Stack of Plates

The last plate placed on top is usually the first plate taken out.

The last plate placed on top is the first plate that can be removed.

04 Core Idea

LIFO

Last In, First Out

The newest item added to the stack is the first item removed.

Last In, First Out means removal order is the reverse of insertion order.

07 Stack Operations

Four Important Actions

push

Add an item to the top

peek

Look at the top item

pop

Remove the top item

empty

Check if stack has nothing

push adds, pop removes, peek reads without removing, and empty checks whether an item is available.

08 Important Rule

Only the Top Is Directly Accessible

In a stack, we normally do not remove items from the middle.

  • You add to the top
  • You inspect the top
  • You remove from the top

To reach a deeper item using stack operations, the items above it must be removed first.

09 Real Applications

Where Stacks Appear

  • Undo feature in editors
  • Browser Back button history
  • Method calls in program memory
  • Checking matching parentheses
  • Reversing text or data

Stacks support undo histories, expression evaluation, function calls, and backtracking.

10 Java Tool

Java Has a Stack Class

For this beginner lesson, we will use Java's built-in Stack class.

import java.util.Stack;
11 Create a Stack

Stack of Strings

Stack<String> pages = new Stack<>();

This creates an empty stack named pages. It will store text values.

The generic type String restricts this stack to text values and prevents accidental insertion of another type.

12 Add Items

push()

pages.push("Home");
pages.push("About");
pages.push("Contact");

Each new item goes on top of the previous item.

push(value) places a new item at the top and increases the stack size.

13 Trace It

After Three push() Calls

Contact
About
Home

Contact was pushed last, so Contact is on top.

14 Look at Top

peek()

System.out.println(pages.peek());
Contact

peek() shows the top item but does not remove it.

peek() returns the current top item but leaves the stack unchanged.

15 Remove Top

pop()

System.out.println(pages.pop());
Contact

pop() returns the top item and removes it from the stack.

pop() returns and removes the top item, exposing the item directly below it.

16 After pop()

New Top

About ← top
Home

Contact is gone. About becomes the new top.

17 Check Empty

empty()

System.out.println(pages.empty());
false

false means the stack still has items.

Check empty() before peek() or pop() when the stack might contain no items.

18 Optional Helper

size()

System.out.println(pages.size());

size() tells how many items are currently inside the stack.

19 Full Example

Browser Pages Stack

import java.util.Stack;

public class Main {
    public static void main(String[] args) {
        Stack<String> pages = new Stack<>();

        pages.push("Home");
        pages.push("About");
        pages.push("Contact");

        System.out.println("Top page: " + pages.peek());
        System.out.println("Going back from: " + pages.pop());
        System.out.println("New top: " + pages.peek());
        System.out.println("Is empty? " + pages.empty());
    }
}

26 Mini Algorithm

Reverse a Word

A stack is useful for reversing because the last character entered comes out first.

hello → olleh
27 Plain English First

Reverse Word Recipe

  • Start with an empty stack
  • Push each character of the word
  • While the stack is not empty, pop characters
  • Print each popped character

Pushing characters and then popping them reverses their order because the last character entered comes out first.

28 Code Part 1

Push Each Character

String word = "hello";
Stack<Character> letters = new Stack<>();

for (int i = 0; i < word.length(); i++) {
    letters.push(word.charAt(i));
}

charAt(i) gets one character from the word.

29 Code Part 2

Pop Until Empty

while (!letters.empty()) {
    System.out.print(letters.pop());
}

The exclamation mark ! means “not”. So this means: while the stack is not empty.

30 Full Program

Reverse a Word Using Stack

import java.util.Stack;

public class Main {
    public static void main(String[] args) {
        String word = "hello";
        Stack<Character> letters = new Stack<>();

        for (int i = 0; i < word.length(); i++) {
            letters.push(word.charAt(i));
        }

        while (!letters.empty()) {
            System.out.print(letters.pop());
        }
    }
}
31 Expected Output

Run Result

olleh

The word was reversed because the last letter pushed was popped first.

33 Understanding Check

peek() vs pop()

peek()

Looks at the top item but keeps it in the stack

pop()

Looks at the top item and removes it

Use peek when you only need to inspect the top; use pop when that item should leave the stack.

34 Class Question

Predict the Output

Stack<String> names = new Stack<>();
names.push("Ana");
names.push("Ben");
names.push("Carlo");

System.out.println(names.pop());
System.out.println(names.peek());
  • First output: Carlo
  • Second output: Ben
35 Common Mistake 1

Popping an Empty Stack

Stack<String> items = new Stack<>();
System.out.println(items.pop());
This causes an error because there is no top item to remove.

Calling pop on an empty Stack throws EmptyStackException because no top element exists.

36 Safe Pattern

Check empty() First

if (!items.empty()) {
    System.out.println(items.pop());
} else {
    System.out.println("Stack is empty.");
}

Always check before popping when you are not sure if the stack has items.

A guard condition makes the removal safe and gives the program a chance to show a useful message.

37 Common Mistake 2

Thinking It Works Like a Queue

Stack

Last in, first out

Queue

First in, first out

Next lesson will focus on queues.

38 Simple Big O

Stack Operations Are Fast

  • push → O(1)
  • peek → O(1)
  • pop → O(1)
  • empty → O(1)

Beginner meaning: each operation is one direct action on the top item.

Top-based push, pop, and peek are normally constant-time operations because no full traversal is required.
