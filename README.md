# Data Structures and Algorithms Class Materials

GitHub Pages-ready lesson website for 32 Java-based DSA lessons.

## Academic grouping

- PRELIM: Lessons 1-8
- MIDTERM: Lessons 9-16
- SEMI FINAL: Lessons 17-24
- FINAL: Lessons 25-32

## Publish with GitHub Pages

1. Upload all files in this folder to the root of a GitHub repository.
2. Open repository **Settings > Pages**.
3. Select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save and wait for the published site link.

## Automatic locks

The landing page checks whether each lesson HTML file exists. Leave a lesson file out of the repository to display **Not Yet Available**. Upload the expected file later to unlock it automatically.
