03 Big Idea

Why Learn Another Loop?

A for loop is great when we know how many times to repeat.

A while loop is great when we repeat until something changes.

Example: keep showing a menu until the user chooses Exit.

A while loop is useful when the number of repetitions depends on user input or a condition that is not known in advance.

04 Analogy

while Loop = Keep Asking

🍽️

Imagine a cashier asking: “Do you want to order again?”

While the answer is not “No”, the cashier keeps taking orders.

05 Definition

What is a while Loop?

A while loop repeats a block of code as long as a condition is true.

while (condition) {
    // code to repeat
}

Read it like: “While this is true, keep doing this.”

Java checks the condition before each round and repeats the body only while that condition remains true.

06 Compare

for Loop vs while Loop

for loop

Best when we already know the number of repetitions.

while loop

Best when we wait for a condition to become false.

for: count 1 to 10
while: repeat menu until Exit

Use a for loop for a predictable count and a while loop when repetition should continue until an event or state changes.

07 First Tiny Example

Count from 1 to 5

int number = 1;

while (number <= 5) {
    System.out.println(number);
    number++;
}

This works like a for loop, but the parts are separated.

08 Part 1

Start with a Variable

int number = 1;

This is the starting value. In our example, we start counting at 1.

Without a starting value, Java will not know where to begin.

The control variable must exist before the loop because both the condition and the body may need to use it.

09 Part 2

Check the Condition

while (number <= 5) {

Before every repeat, Java checks: Is number still 5 or less?

  • If true → run the code inside
  • If false → stop the loop

If the condition is false at the beginning, the while-loop body will not run even once.

10 Part 3

Do the Repeated Work

System.out.println(number);

This is the action repeated by the loop.

In this example, Java prints the current value of number.
11 Part 4

Update the Variable

number++;

This increases number by 1 after every repeat.

Without an update, the loop may never stop.

Changing the control variable inside the loop is what allows the condition to eventually become false.

12 Trace

How Java Reads It

Round 1

number = 1 → print 1 → add 1

Round 2

number = 2 → print 2 → add 1

Round 3

number = 3 → print 3 → add 1

Stops

When number becomes 6, condition is false.

The cycle is condition, body, update, then condition again; Java leaves the loop as soon as the condition is false.

17 Important Warning

Infinite Loop

An infinite loop happens when the condition never becomes false.

int number = 1;

while (number <= 5) {
    System.out.println(number);
    // number never changes here
}
This may keep printing forever.

An infinite loop occurs when the condition always stays true, often because the control value is never updated.

18 Fix It

Always Move Toward Stopping

int number = 1;

while (number <= 5) {
    System.out.println(number);
    number++;
}

Because number increases, it will eventually become 6 and stop.

Each repetition should change some value or state so the program gets closer to its exit condition.

20 while vs if

Not the Same

if

Checks once. Runs once if true.

while

Checks again and again. Repeats while true.

if (choice != 3) {
    // runs once
}

while (choice != 3) {
    // repeats until choice is 3
}
21 Real Use

Menus Need while Loops

A menu should not disappear after one choice.

  • Show options
  • Ask the user to choose
  • Run the selected action
  • Show the menu again
  • Stop only when the user chooses Exit

Menus repeat because the user may choose several actions before selecting the exit option.

25 Menu Loop

Repeat Until Exit

while (choice != 3) {
    // show menu
    // read choice
    // respond to choice
}

The symbol != means “not equal to”.

The user choice acts as the loop-control value; entering the exit number makes the condition false.

Get the Number

Use if and else if

if (choice == 1) {

    System.out.println("Keep practicing!");

32 Copy and Run

Complete Menu Code

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int choice = 0;

        while (choice != 3) {
            System.out.println("1. Say hello");
            System.out.println("2. Show message");
            System.out.println("3. Exit");
            System.out.print("Choose: ");
            choice = input.nextInt();

            if (choice == 1) {
                System.out.println("Hello!");
            } else if (choice == 2) {
                System.out.println("Keep practicing!");
            }
        }
    }
}

35 Improve It

Add an Exit Message

if (choice == 1) {
    System.out.println("Hello!");
} else if (choice == 2) {
    System.out.println("Keep practicing!");
} else if (choice == 3) {
    System.out.println("Goodbye!");
}

Now the program clearly tells the user that it is ending.

36 Improve It

Handle Invalid Choices

else {
    System.out.println("Invalid choice. Try again.");
}

This catches numbers like 4, 9, or 100.

Good programs help users recover from mistakes.

An else branch can explain invalid input without ending the menu, allowing the user to try again.

37 Common Mistake

Missing Scanner Import

error: cannot find symbol Scanner
// Make sure this is at the top:
import java.util.Scanner;

Scanner is not automatic. We must import it first.

38 Common Mistake

Wrong Loop Condition

// WRONG: this stops immediately if choice is 0
while (choice == 3) {
    // menu code
}

// CORRECT: repeat while choice is not 3
while (choice != 3) {
    // menu code
}

Read the condition out loud to check your logic.

39 Common Mistake

Choice is Not Updated

int choice = 0;

while (choice != 3) {
    System.out.println("1. Hello");
    System.out.println("3. Exit");
    // missing: choice = input.nextInt();
}
The loop keeps using the old value of choice.

If the program never reads a new choice inside the loop, it keeps processing the old value and may never stop.

40 Common Mistake

Using = Instead of ==

// WRONG
if (choice = 1) {
    System.out.println("Hello!");
}

// CORRECT
if (choice == 1) {
    System.out.println("Hello!");
}

= assigns a value. == compares two values.
