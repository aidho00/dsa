The Kitchen Analogy

Three Ideas.
One Kitchen.

We will use cooking to understand programming. The recipe represents the algorithm, the containers organize the ingredients like data structures, and the kitchen represents the program carrying out the work.

04 Analogy Part 1

Algorithm = Recipe

📋
Recipe Ordered cooking steps
→
🧠
Algorithm Ordered problem-solving steps

A recipe works only when its instructions are clear and ordered. An algorithm follows the same rule so another person or computer can carry out the task correctly.

05 Definition

What Is an Algorithm?

An algorithm is a clear sequence of steps used to solve a problem or complete a task.

The steps should be understandable, ordered, and able to finish.

06 Example Algorithm

Cooking Rice

  1. Measure the rice.
  2. Wash the rice.
  3. Add the correct amount of water.
  4. Place it in the rice cooker.
  5. Press Cook.
  6. Wait until the rice is ready.
07 Think First

Does the Order Matter?

What might happen if you press Cook before adding rice and water?

The same steps in the wrong order may produce the wrong result.

08 A Weak Algorithm

“Just Cook the Rice”

Step 1: Cook the rice.

This is too vague. It does not tell a beginner what to prepare, what to do first, or when to stop.

A good algorithm gives enough detail for someone to follow it.

09 Algorithm Check

Three Beginner Questions

🔍

🔢

Choosing the right container makes ingredients easier to store and find. In the same way, choosing the right data structure makes information easier to access, update, and process.

12 Definition

What Is a Data Structure?

A data structure is a way of organizing and storing information so it can be used efficiently.

Different structures are useful for different tasks.

The algorithm and data structure solve different parts of the problem: one defines the process, while the other keeps the required information organized.

17 Simple Comparison

What Is the Main Difference?

📋

Algorithm

Focuses on what steps should be followed.

🗃️

Data Structure

Focuses on how information is organized.

💻

Program

Uses code to perform the steps using the organized information.

18 Scenario

Finding the Highest Grade

Grades:
85, 92, 78, 90
→
Check each grade
→
Highest = 92
Data structure: the organized collection of grades
Algorithm: the steps used to compare the grades

The grades remain the stored data. The comparison process examines each value and keeps the largest value found so far until the list is finished.

Check for Understanding

Which One Is the Algorithm?

A. The list of grades B. The steps for finding the highest grade

27 Common Error 1

Missing Quotation Mark

// ❌ Wrong
System.out.println("Hello);
// ✅ Correct
System.out.println("Hello");

Text must begin and end with double quotation marks.

28 Common Error 2

Missing Semicolon

// ❌ Wrong
System.out.println("Hello")
// ✅ Correct
System.out.println("Hello");

A Java statement commonly ends with a semicolon.

29 Common Error 3

Changing Main

Do not rename Main while using the default OnlineGDB setup.
public class Main {

Java is case-sensitive. Main and main are not the same.

30 Debugging Routine

When the Program Does Not Run

  1. Read the first error message.
  2. Check the line number mentioned.
  3. Check the line above it too.
  4. Look for missing quotes, parentheses, braces, or semicolons.
  5. Change only one thing, then run again.

Start with the first reported error because later messages may be side effects of that first problem. Fix one issue, run again, and then read the new result.
