04 Real-Life Analogy

Sorting Playing Cards

Imagine you are holding cards in your hand.

  • You pick up one card from the unsorted pile
  • You compare it with the cards already in your hand
  • You slide bigger cards to the right
  • You insert the new card into the correct position
05 Simple Definition

What is Insertion Sort?

Insertion Sort builds a sorted part one value at a time by inserting each new value into the correct position.

Keyword: insert. We do not simply swap once. We may need to shift several values first.

Insertion sort takes one value from the unsorted section and inserts it into the correct position in the sorted section.

06 Big Picture

The Array Has Two Parts Again

Sorted Left Side

Values already arranged.

Unsorted Right Side

Values still waiting to be inserted.

At the start, we treat the first value as already sorted.

The left side stays sorted after every pass, while the right side still contains values to insert.

07 Important Rule

Start at Index 1

[ 5, 3, 4, 1 ]

Index 0 is a one-item sorted part. We start inserting from index 1.

A one-element section is already sorted, so the first value that needs insertion is at index 1.

08 Vocabulary

Words We Need for the Code

  • i - the position of the value we want to insert
  • current - the value we are holding temporarily
  • previous - the position before current
  • shift - move a bigger value one step to the right
  • insert - place current into the open spot

28 Code Build-Up

Step 3: Save the Current Value

static void insertionSort(int[] numbers) {
    for (int i = 1; i < numbers.length; i++) {
        int current = numbers[i];

    }
}

We save the current value because some array positions may be overwritten while shifting.

Store the current value before shifting larger elements, or the value being inserted may be overwritten.

29 Code Build-Up

Step 4: Look Backward

static void insertionSort(int[] numbers) {
    for (int i = 1; i < numbers.length; i++) {
        int current = numbers[i];
        int previous = i - 1;

    }
}

previous starts one position before current.

Insertion sort compares the saved value with elements to its left because that is the sorted section.

30 Code Build-Up

Step 5: While Bigger Values Exist

while (previous >= 0 && numbers[previous] > current) {
    // shift bigger values to the right
}

The loop continues while we are still inside the array and the previous value is bigger than current.

Continue shifting while the previous index is valid and its value is greater than current.

31 Code Build-Up

Step 6: Shift Right

numbers[previous + 1] = numbers[previous];
previous--;

Move the bigger value one position to the right, then move previous one step left.

Copying a larger value one position right creates space without losing the saved current value.

32 Code Build-Up

Step 7: Insert Current

numbers[previous + 1] = current;

When shifting stops, previous + 1 is the correct open position.

After shifting stops, previous + 1 is the open position where current belongs.

33 Complete Method

Insertion Sort Method

static void insertionSort(int[] numbers) {
    for (int i = 1; i < numbers.length; i++) {
        int current = numbers[i];
        int previous = i - 1;

        while (previous >= 0 && numbers[previous] > current) {
            numbers[previous + 1] = numbers[previous];
            previous--;
        }

        numbers[previous + 1] = current;
    }
}

This is the main algorithm. Read each line slowly and connect it to the card analogy.

35 Full Java Program

Copy and Run in OnlineGDB

public class Main {
    static void insertionSort(int[] numbers) {
        for (int i = 1; i < numbers.length; i++) {
            int current = numbers[i];
            int previous = i - 1;

            while (previous >= 0 && numbers[previous] > current) {
                numbers[previous + 1] = numbers[previous];
                previous--;
            }

            numbers[previous + 1] = current;
        }
    }

    static void printArray(int[] numbers) {
        for (int i = 0; i < numbers.length; i++) {
            System.out.print(numbers[i] + " ");
        }
        System.out.println();
    }

    public static void main(String[] args) {
        int[] numbers = {5, 3, 4, 1};

        System.out.println("Before sorting:");
        printArray(numbers);

        insertionSort(numbers);

        System.out.println("After sorting:");
        printArray(numbers);
    }
}

40 Common Mistake

Forgetting to Save current

// Correct:
int current = numbers[i];

We save current before shifting because the original value at numbers[i] may be overwritten.

41 Common Mistake

Wrong While Condition Order

// Safer order:
while (previous >= 0 && numbers[previous] > current) {
    numbers[previous + 1] = numbers[previous];
    previous--;
}

Check previous >= 0 first before accessing numbers[previous].

Check previous >= 0 before reading array[previous] to avoid using a negative index.

42 Common Mistake

Inserting at previous Instead of previous + 1

// Correct:
numbers[previous + 1] = current;

When the loop stops, previous is already one step before the open position.

43 Mental Model

Why previous + 1?

previous moved too far left.
The correct empty spot is one step to the right.

This is one of the most important details in Insertion Sort.

When the loop stops, previous points one position before the correct insertion location.

44 Compare Algorithms

Bubble vs Selection vs Insertion

Bubble

Swap neighbors repeatedly.

Selection

Find smallest, swap once.

Insertion

Shift bigger values, insert current.

All three are beginner-friendly sorting algorithms, but each uses a different strategy.

Bubble swaps neighbors, selection chooses a minimum, and insertion shifts values to place one current item.

45 Simple Big O

How Much Work?

  • Best case: if the array is already sorted, shifting is minimal
  • Worst case: many values may shift for each current value
  • A loop inside another loop can lead to O(n^2)
  • Insertion Sort can feel natural for small or nearly sorted lists

Insertion sort is quadratic in the worst case but can be efficient when data is already nearly sorted.
