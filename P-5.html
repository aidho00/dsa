03 Big Idea

What is an Operator?

An operator is a symbol that tells Java what action to perform.

+

Add values

*

Multiply values

>

Compare values

An operator tells Java to perform an action on one or more values, such as adding numbers or comparing two results.

04 Analogy

Operators are Action Buttons

Think of Java like a calculator. The numbers are the values, and the operators are the buttons you press.

  • Press + to combine values
  • Press - to subtract values
  • Press * to multiply values
  • Press / to divide values
05 Main Categories

Three Operator Groups Today

Arithmetic

Calculates numbers

Comparison

Checks relationship

Logical

Combines conditions

We start with the easiest: arithmetic.

Arithmetic operators calculate values, comparison operators produce true or false, and logical operators combine boolean conditions.

09 Subtraction

Using -

int a = 17;

12

Subtraction follows the order from left to right.

10 Multiplication

Using *

int a = 17;
int b = 5;
System.out.println(a * b);
85

In Java, multiplication uses an asterisk, not x.

11 Division

Using /

int a = 17;
int b = 5;
System.out.println(a / b);
3

Important: int divided by int gives an int answer. The decimal part is removed.

12 Important Warning

Integer Division

Math answer

17 / 5 = 3.4

Java int answer

17 / 5 = 3

Java does not round. It simply removes the decimal part when both values are int.

When both operands are integers, Java removes the decimal part of the quotient instead of rounding it.

13 Remainder

Using %

int a = 17;
int b = 5;
System.out.println(a % b);
2

17 divided by 5 gives 3 groups, with 2 left over.

14 Visual Idea

Why 17 % 5 is 2

17 items
5 + 5 + 5 = 15
17 - 15 = 2 left over

The left over value is the remainder.

The modulo operator returns the remainder after division: 17 contains three groups of 5 with 2 left over.

18 Order of Operations

Java Follows Math Rules

System.out.println(2 + 3 * 4);

Will the answer be 20 or 14?

Multiplication happens before addition.

Multiplication, division, and modulo are evaluated before addition and subtraction unless parentheses specify another order.

19 Parentheses

Control the Calculation

System.out.println(2 + 3 * 4);
System.out.println((2 + 3) * 4);
14
20

Parentheses tell Java which part to solve first.

20 Variables

Store the Result

int length = 8;
int width = 5;
int area = length * width;
System.out.println(area);

The calculation happens first, then the result is stored in area.

Saving a calculation in a variable makes the result reusable in later output, comparisons, or additional calculations.

21 Readable Output

The + symbol can also join text and values.

22 Scanner + Math

Ask, Calculate, Print

import java.util.Scanner;
public class Main {
public static void main(String[] args) {
Scanner input = new Scanner(System.in);
System.out.print("Length: ");
int length = input.nextInt();
System.out.print("Width: ");
int width = input.nextInt();
int area = length * width;
System.out.println("Area: " + area);
}
}
23 Comparison

Comparison Operators

== equal to
!= not equal to
> greater than
< less than
>= greater than or equal
<= less than or equal

A comparison gives only one of two answers: true or false.

A comparison produces a boolean value. Java can then use that true-or-false result to make a decision.

24 Boolean Result

Compare Two Numbers

int score = 85;
System.out.println(score >= 75);
true

Because 85 is greater than or equal to 75.

25 Careful

= is Not the Same as ==

score = 75

Assignment: store a value

score == 75

Comparison: check equality

This is one of the most common beginner mistakes.

A single equals sign assigns a value, while two equals signs compare two values for equality.

26 Preview

Comparisons Help if Statements

int score = 85;
if (score >= 75) {
System.out.println("Passed");
}

Next lesson, we will use conditions more deeply.

27 Logical Operators

Combining Conditions

&& AND
|| OR
! NOT

Logical operators are useful when one condition is not enough.

28 AND

&& Means Both Must Be True

int age = 20;
boolean hasId = true;
System.out.println(age >= 18 && hasId);
true

The AND operator produces true only when the condition on the left and the condition on the right are both true.

29 OR

|| Means At Least One is True

boolean hasCash = false;
boolean hasCard = true;
System.out.println(hasCash || hasCard);
true

The OR operator produces true when either condition is true; it is false only when both conditions are false.

30 NOT

! Reverses the Answer

boolean isAbsent = false;
System.out.println(!isAbsent);
true

Not absent means present.

The NOT operator changes true to false and false to true, which is useful when testing that something is not allowed or not present.

31 DSA Connection

Why % Matters in Algorithms

The remainder operator is small, but very useful.

  • Check if a number is even or odd
  • Group items into repeating patterns
  • Cycle through positions in some data structures
  • Prepare for hashing later in the course
32 Even or Odd

Use % 2

int number = 10;
System.out.println(number % 2);
0

If number % 2 is 0, the number is even.

An even integer leaves a remainder of 0 when divided by 2, while an odd integer leaves a remainder of 1.

39 Common Mistake

Using x Instead of *

int area = length x width;
int area = length * width;

Java does not understand x as multiplication.

40 Common Mistake

Forgetting Parentheses

// Different answers
System.out.println(2 + 3 * 4);
System.out.println((2 + 3) * 4);

When in doubt, use parentheses to make your intention clear.

Parentheses make the intended order explicit and prevent a correct formula from being evaluated in the wrong sequence.

41 Common Mistake

Confusing = and ==

if (score = 75)
if (score == 75)

Use == when asking: Are these two values equal?
