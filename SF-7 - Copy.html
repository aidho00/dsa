03 Big Idea

What is a Linked List?

A linked list is a collection of nodes where each node stores data and a link to the next node.

Instead of one row of boxes like an array, a linked list is a chain of connected boxes.

A linked list stores values in node objects connected by references instead of requiring adjacent array positions.

05 Array vs Linked List

Two Ways to Store Many Values

Array

Values are placed beside each other using indexes.

ArrayList

Like an array, but Java can resize it for us.

Linked List

Values are stored in nodes connected by arrows.

Arrays provide direct index access, while linked lists move from node to node through links.

20 addFirst Code

The Complete Method

void addFirst(int value) {
    Node newNode = new Node(value);
    newNode.next = head;
    head = newNode;
}

Three lines only, but the order is very important.

21 Important Warning

Do Not Reverse the Order

If you write head = newNode first, you may lose the old list because the new node has not been connected yet.
// Correct order
newNode.next = head;
head = newNode;

Updating head too early loses the reference needed to connect the new node to the old list.

24 while Loop

Stop When Current Becomes null

while (current != null) {
    System.out.print(current.data + " -> ");
    current = current.next;
}
  • Print the current node's data
  • Move current to the next node
  • Stop when there is no next node

The loop must stop before accessing fields through null, which marks the position after the last node.

Third Operation

countNodes()

Counting nodes uses the same traversal pattern, but we add 1 for every node we visit.

Counting is a traversal: begin at head, add one per node, and move current forward each round.

28 Counting Logic

Start at Zero

int count = 0;

Before visiting nodes, we have counted nothing yet.

29 Counting Logic

Add One for Each Node

while (current != null) {
    count++;
    current = current.next;
}

Every time current points to a real node, count goes up by 1.

30 countNodes Code

The Complete Method

int countNodes() {
    int count = 0;
    Node current = head;

    while (current != null) {
        count++;
        current = current.next;
    }

    return count;
}

        newNode.next = head;
        head = newNode;

40 Common Mistake 1

Forgetting current = current.next

while (current != null) {
    System.out.print(current.data);
    // current never moves
}
This creates an infinite loop because current stays on the same node forever.

Without advancing current, the loop stays on the same node forever.

41 Common Mistake 2

Changing Head While Printing

while (head != null) {
    System.out.println(head.data);
    head = head.next;
}
This destroys your starting point. Use a temporary reference named current instead.

Moving head during printing destroys the list entry point; use a temporary traversal reference instead.

42 Common Mistake 3

Accessing data when current is null

System.out.println(current.data);

If current is null, there is no node to read. Always check current != null first.

Check current before reading current.data to prevent a NullPointerException.
